About this console

Vantage unifies open-source and native engines behind one product: it plans which engines to run per target, validates and correlates their output into one finding per weakness, scores risk, and attaches a reproducible, tamper-evident Proof-of-Vulnerability to each. This console is served by the control plane and talks to its REST API. It works air-gapped (no external resources).
